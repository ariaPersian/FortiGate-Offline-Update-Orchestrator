# v0.5.2 FortiGate prompt guard

FortiGate CLI prints TFTP transfer progress as lines containing only `#` characters.
The previous prompt matcher accepted those progress bars as shell prompts, so the agent could
advance to post-restore verification before the package transfer completed and close the SSH
session prematurely.

Version 0.5.2 routes `fgops-agent` through a prompt guard that rejects hash-only progress lines
while preserving normal prompts such as `SITEC-FW-02 (global) #`.

A failed archive remains non-replayable until an operator explicitly resets it after confirming
that the expected FortiGuard object versions did not change.
